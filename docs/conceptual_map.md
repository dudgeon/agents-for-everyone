# Conceptual Map — The Bone Structure

_This document will hold the era framework, narrative arc, and thematic structure once we agree on them in Phase 1. It's the skeleton that everything else hangs on._

## Narrative Arc (Draft — Not Yet Approved)

```
Act 1: "Remember When..." (~2/3 of book)
  Maven introduces the robot/agentic tool
  Skeptic is unimpressed, takes Maven back through time
  For each era:
    - What could it do? (honest capabilities)
    - How did it fail? (dramatic/comedic failures)
    - What was still missing? (the gap)
    - Maven's "but wait, then..." (bridge to next era)
  Skeptic's resistance gradually softens as the cumulative progress becomes undeniable

Act 2: "Show Me" (~1/3 of book)
  Skeptic is convinced enough to try
  Maven guides Skeptic through building their own agentic setup
  Curriculum unfolds through a concrete project/task
  Culminates in: Skeptic understands nurturing, alignment, CLAUDE.md, skills
  Emotional beat: this isn't magic — it's a practice
```

## Thematic Threads

These themes should weave through the entire story:

1. **Harness > Model**: The tooling around the model matters more than raw intelligence
2. **Trust is Earned**: The Skeptic's distrust is rational; it has to be overcome with evidence
3. **Alignment Through Investment**: Agentic tools get better the more you invest in shaping them
4. **The File System is the Interface**: Moving from chat bubbles to file-system-native work is a paradigm shift
5. **Failure is Informative**: Each era's failures point to what the next era needs to solve
