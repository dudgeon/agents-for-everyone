# Appendix: What Next

Content ideas for the "What Next" appendix — practical next steps for readers.

## Key Points

1. **Rules encode values, constraints, guiding principles** — get good at defining and sharing these. This is the primary mechanism for aligning agent behavior.

2. **Agents need end effectors** — including access to your primary data sources, whether structured (Snowflake) or unstructured (Slack). An agent without tools is just a chatbot.

3. **People need to meet agents halfway** — for now, to get the most leverage, people need to learn some new SWE primitives (especially if their work is non-SWE):
   - **Markdown** — the lingua franca of agent instructions and knowledge
   - **Git** — version control for your agent's memory and your collaboration with it
   - **Terminal** — the interface where agentic work actually happens
