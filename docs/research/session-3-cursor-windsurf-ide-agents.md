- Aug 2025: Linear integration (assign issues to Cursor)

### Cursor Tab vs Agent Mode
- Tab: predicts entire code blocks, can modify/add/delete multiple lines around cursor, uses proprietary lightweight model
- Agent: fully autonomous, edits files, runs terminal commands, multi-file edits, uses codebase indexing
- Different models with different update cadences

### Background Agents Cost
- Each task costs additional tokens (an easy PR costs ~$4.63 during preview)
- Requires Pro ($20/month)

### Cascade Details
- Tracks: edits, terminal commands, conversation history, clipboard, linter output
- Built-in planning agent continuously refines long-term plan in background
- Two modes: "Code" (creates/modifies) and "Chat" (answers questions)
- Approval gates before terminal commands

### The 72-Hour Windsurf Saga
- OpenAI exclusivity period expired

- Non-exclusive licensing rights to Windsurf technology
