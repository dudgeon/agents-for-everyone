### CLAUDE.md Hierarchy
- Root CLAUDE.md, parent directories (monorepo), home folder (universal), child directories (on-demand)
- `/init` command auto-generates CLAUDE.md
- Later expanded with `.claude/rules/` for splitting into focused rule files

### Hooks Types
- `"type": "command"` (shell command)
- `"type": "prompt"` (single-turn model evaluation)
- `"type": "agent"` (multi-turn verification with tool access)
- Access via `/hooks` command

### Skills Evolution
- Skills follow the Agent Skills open standard
- SKILL.md files placed in `.claude/skills/` folders
- YAML frontmatter controls invocation (manual vs automatic by Claude)
- Subagent execution, dynamic context injection

### Claude Code on Web (claude.ai/code)
- Asynchronous coding agent in isolated sandboxed environments
- GitHub access supervised by secure proxy
- "Teleport" feature copies chat transcript AND edited files to local CLI
- Internet access configurable: no internet, limited, or full

### Agent Teams (Feb 2026)
- Unlike subagents (report to parent), agent teams enable actual collaboration
- Teammates share findings and coordinate independently
- First-class feature with Opus 4.6

### C Compiler Proof of Concept
- ~2,000 Claude Code sessions, $20,000 in API costs
- Agent team produced 100,000-line C compiler
- Can build Linux 6.9 on x86, ARM, and RISC-V
- Documented in Anthropic engineering blog

### Claude Code vs Cursor (Independent Testing)
- Claude Code uses 5.5x fewer tokens for identical tasks
- 30% less code rework (gets it right first/second iteration)
- Claude Code: true 200K-token context; Cursor: effective capacity can be reduced
- Cursor leads on: setup speed, Docker/deployment workflows, certain code quality metrics
