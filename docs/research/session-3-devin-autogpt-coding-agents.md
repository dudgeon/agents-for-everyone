### Devin Details
- Founders: Scott Wu (IOI 2014 first place, 3 golds), Steven Hao, Walden Yan — all IOI gold medalists
- Demo scenarios: Game of Life website, sympy bug fix, CV model report, Upwork jobs, engineering interviews
- Carl Brown (Internet of Bugs): Upwork client asked for setup instructions (docs), not code. Devin wrote code. A file Devin "debugged" didn't exist in original repo.
- Brown replicated actual customer request in ~30 minutes vs Devin's 6+ hours
- Stripe CEO Patrick Collison: "very impressive in practice"
- Perplexity CEO Srinivas: "first demo that seems to cross the threshold"
- Eric Glyman (Ramp): "single most impressive demo I've seen in the past decade"
- Series A (Mar 2024): $21M at $350M (Founders Fund)
- Series A extension (Apr 2024): $175M at $2B (Founders Fund) — turned down offers closer to $1B
- GA Dec 2024 at $500/month
- Devin 2.0 (Apr 3, 2025): $20/month minimum, Agent-Native IDE, Interactive Planning, Devin Search, Devin Wiki
- Windsurf acquisition brought $82M ARR, 350+ enterprise customers
- $400M round at $10.2B (Sep 2025)

### Copilot Agent Mode Details
- Feb 24, 2025: Agent Mode previewed in VS Code
- Can independently identify subtasks, edit multiple files, run terminal commands, iterate on errors
- May 2025 (Build): Async Coding Agent — assign GitHub issue, spins up dev env via GitHub Actions, pushes commits to draft PR
- Excels at "low-to-medium complexity tasks in well-tested codebases"
- "Project Padawan" — fully autonomous agent for entire issues
- Open-sourced Copilot Chat in VS Code
