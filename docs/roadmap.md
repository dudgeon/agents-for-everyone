# Roadmap

## Development Phases

### Phase 1 — Concept Architecture ← CURRENT
**Status**: In progress
**Goal**: Lock in characters, tone, narrative structure, and the era framework before any writing begins.

Deliverables:
- [ ] Character profiles finalized (docs/characters.md)
- [ ] Tone and voice agreed upon
- [ ] Era framework defined — discrete time windows with template per era
- [ ] Narrative arc mapped — emotional beats, turning points
- [ ] Format decision (prose, graphic novel, hybrid)
- [ ] Scope decision (word count target, number of chapters/sections)

Open questions: see docs/backlog.md

### Phase 2 — Era Research & Bone Structure
**Status**: Not started
**Goal**: Populate each era with real, researched data. Validate era boundaries.

Deliverables:
- [ ] Research file per era in docs/research/
- [ ] Each era populated with: release dates, capabilities, limitations, cultural moments, notable failures, what the Skeptic would say, what the Maven would concede
- [ ] Era boundaries finalized (how many? where do they split?)
- [ ] Key anecdotes and failure stories selected

### Phase 3 — Curriculum Design
**Status**: Not started
**Goal**: Design the learning progression for the final third of the book.

Deliverables:
- [ ] Primitives list: what concepts must a reader understand?
- [ ] Task design: teenager-oriented knowledge work scenarios
- [ ] Learning progression: what builds on what
- [ ] Mapping of primitives to story beats

### Phase 4 — Narrative Design
**Status**: Not started
**Goal**: Scene-by-scene outline, dialog style, integration of technical content into story.

Deliverables:
- [ ] Chapter/scene outline
- [ ] Dialog style guide
- [ ] Technical content integration plan (how do we teach without lecturing?)

### Phase 5 — Drafting
**Status**: Not started
**Goal**: Write the actual story in sections.

### Phase 6 — Format & Polish
**Status**: Not started
**Goal**: Final format decisions, visual design, editing passes.
